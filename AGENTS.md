# Instrucciones del proyecto

La aplicación se llama Quantlabs LY-KY-Q.

Por instrucción del propietario, en cada actualización:
- Incrementar la versión SemVer de frontend/package.json y sincronizar frontend/package-lock.json.
- Actualizar README.md, incluida su versión e historial de cambios.
- Verificar con npm run build en frontend cuando corresponda.
- Crear un commit con los cambios y publicar en origin/main cuando sea posible.

No versionar credenciales, entornos virtuales, node_modules, dist, modelos generados ni trades.jsonl.
La versión inicial publicada es 0.1.0.
